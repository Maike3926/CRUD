## 📖 Sobre o Projeto

Este projeto consiste numa **API RESTful** desenvolvida utilizando as melhores práticas do ecossistema **Java** e **Spring Framework**. O objetivo principal é fornecer uma infraestrutura sólida, altamente testável e pronta para servir de base a microsserviços modernos.

---

## 🛠️ Tech Stack & Ferramentas

* **Linguagem:** Java 25 (LTS Features & Performance)
* **Framework Backend:** Spring Boot 3
* **Web Engine:** Spring MVC
* **Build System:** Apache Maven
* **Ambiente de Desenvolvimento:** IntelliJ IDEA Enterprise
